# This or That (T\|T) — Full Feature Inventory

This is the exhaustive, ground-truth list of everything the app currently does, pulled directly
from the codebase (not from marketing copy). Use this as the source of truth when writing
marketing content, release notes, or onboarding docs — `marketing/` builds on top of this file.

Live product: https://thisthatpicks.com

---

## 1. MLB Betting Picks (original core product)

- **Daily moneyline picks** for every MLB game, generated by a statistical model each morning.
- **Verdict system** — every pick is tagged `CLEAN`, `BET`, `PASS`, or `TRAP` (see `README.md` for
  the full model explanation), plus a `HALF SIZE` flag when late-game bullpen risk is elevated.
- **Confidence score (0–10)** per pick, with a 6.5 minimum bar for any actionable verdict.
- **AI-written breakdowns** — Claude generates a narrative analysis per pick covering matchup
  context, starting pitcher form, and bullpen state (`lib/mlb-picks.js`).
- **"Steals"** — a curated feed of the single highest-edge picks across the board, surfaced as
  their own tab (`app/api/steals`).
- **Player props** — prop picks (hits, strikeouts, total bases, etc.) generated and cached
  alongside moneyline picks (`app/api/props`, `app/api/prop-lines`).
- **Live score overlay** — picks serve from cache but overlay real-time scores on every request.
- **Model record / win-loss tracking** — public W-L record with a monthly calendar view
  (`app/record`) and model performance analytics.
- **Team & player pages** — searchable team and player profiles with stats, schedules, and logos
  (`components/TeamsSection.js`, `components/PlayersSection.js`, `app/api/team`, `app/api/player`,
  `app/api/search`).
- **Schedule view** — full slate browsing by date (`components/ScheduleSection.js`).
- **Free daily pick** — one pick exposed to logged-out users as a funnel/teaser
  (`app/api/free-pick`).

## 2. NFL Betting

- **NFL moneyline/spread picks**, generated weekly (`app/api/nfl/picks`, cron: Tuesdays).
- **NFL player props** (`lib/nfl-odds-props.js`).
- **Depth charts** per team, with injury-status overlays (`app/api/nfl/depth-chart`,
  `lib/nfl-roster.js`).
- **Team schedules and daily/weekly record tracking** for NFL, mirroring the MLB record features
  (`app/api/nfl/team-schedule`, `app/api/nfl/today-record`, `app/api/nfl/daily-record`).

## 3. NFL Fantasy Football Suite

This is the newest and largest product surface in the app (`components/NFLSection.js`,
`lib/nfl-fantasy/*`, `app/api/nfl/fantasy/*`).

- **Fantasy Cheat Sheet / Rankings** — weekly-computed player rankings by scoring format (PPR,
  half-PPR, standard) and position, with:
  - Projected points, floor/ceiling, and **VORP** (value over replacement) — `lib/nfl-fantasy/vorp.js`
  - **Gap-detection tiering** — tiers break at statistically meaningful gaps in the rankings rather
    than fixed cutoffs (`lib/nfl-fantasy/tiers.js`)
  - **ADP and value-delta badges** — flags players being drafted later/earlier than their model
    rank warrants (`lib/nfl-fantasy/adp.js`)
  - **Expected-vs-actual regression tracking** — flags players over/underperforming their
    projection with a "regression coming" signal (`lib/nfl-fantasy/regression.js`)
  - Adjustments layered on top of the base projection: **pace-of-play**, **play-caller
    tendencies**, **offensive-personnel usage**, and **strength-of-schedule** adjustments
    (`lib/nfl-fantasy/pace-adjustment.js`, `playcaller-adjustment.js`, `personnel-adjustment.js`,
    `schedule-adjustment.js`)
  - Injury status/risk flags (`lib/nfl-fantasy/injury.js`)
  - "Trending" add counts and news blurbs per player (`lib/nfl-fantasy/news.js`, Sleeper trending
    data via `lib/nfl-fantasy/sleeper.js`)
- **Draft Assistant** — an on-the-clock live draft tool (`lib/nfl-fantasy/draft-assistant.js`,
  `app/api/nfl/fantasy/draft`):
  - Turns cheat-sheet ranks into "who to actually draft now" given who's already off the board and
    what your roster still needs
  - Computes **positional roster needs** (starters + FLEX deficit) and applies a scarcity bonus so
    a marginal starter-need pick can outrank a higher-ranked bench pick
  - **Snake-draft turn math** — tracks whose turn it is and how many picks until you're on the
    clock
  - **Sleeper league sync** — syncs live draft state from a connected Sleeper league, polled every
    4s for a fast on-the-clock read
  - Persists draft picks and renders your team as a full starting-lineup card, not just a pick list
  - **Account-scoped saves** (`app/api/nfl/fantasy/draft-teams`) — save a draft snapshot to your
    account (not just localStorage) so it follows you across devices, track more than one draft at
    once (e.g. two leagues), and generate a public read-only share link for any saved team
    (`app/draft-team/[token]`)
- **Fantasy backtesting** — projections are validated against realized historical seasons via a
  dedicated backtest runner (`lib/nfl-fantasy/backtest-runner.js`, `npm run fantasy-backtest`),
  distinct from the MLB backtest system.
- **Free-tier gating** — a limited free usage tier for fantasy features before requiring Pro
  (`sql/017_fantasy_free_usage.sql`).

## 4. AI Chat Assistant

- **In-app betting chat** — a Claude-powered (Haiku) assistant scoped to the day's picks data; it
  highlights the highest-edge games, flags value underdogs, and can suggest parlay combinations
  from the board (`app/api/chat`, system-prompted to stay under 200 words and mobile-formatted).
- **AI-generated game recaps** — post-game boxscore summaries generated via Claude from live MLB
  boxscore/linescore data (`app/api/tracker/game-recap`).

## 5. Bet Tracker / Portfolio

- **Personal pick tracker** — users can save picks and track P&L against their own stake sizing,
  surfaced as a "Portfolio" tab distinct from the betting board itself (push results excluded from
  win/loss rate).
- **Searchable tracker history**.

## 6. Monetization

- **Stripe subscriptions** — full checkout, webhook-driven entitlement sync, and self-serve
  billing portal (`app/api/stripe/checkout`, `.../webhook`, `.../portal`, `lib/stripe.js`).
  Monthly and season-long price tiers.
- **Access codes** — invite-style codes that grant free Pro access, validated server-side at
  redemption (`app/api/redeem-code`, `app/admin/codes`).
- **Free vs. Pro gating** — free tier gets one MLB pick/day + limited fantasy usage; Pro unlocks
  the full board, all breakdowns, edge scores, and full fantasy tools.
- **Account management** — self-serve account deletion (`app/api/account/delete`).

## 7. Distribution / Growth Channels

- **Email digest** — daily pick digest sent to subscribers via Resend, plus a weekly summary email
  (`app/api/cron/email`, `app/api/cron/weekly`).
- **Twitter/X bot** — top picks posted automatically once daily; admin can also post manually
  (`app/api/cron/tweet`, `app/admin/tweet`). Handle: `@ThisorThatPicks`.
- **Open Graph image generation** — dynamic OG images for share cards (`app/api/og`).
- **Marketing landing page** — a separate, animated landing page independent of the logged-in app
  shell, with a live model-record stat strip and blurred pick previews as a conversion hook
  (`app/landing`).

## 8. Admin & Internal Ops

All under `app/admin`, gated by `NEXT_PUBLIC_ADMIN_EMAILS`.

- **Admin dashboard** — the largest single page in the app (~1,700 lines): pick management,
  manual regeneration, system health, and analytics in one place.
- **Backtest console** — run and inspect backtests, calibration curves, and edge histograms
  in-browser (`app/admin/backtest`, `components/backtest/*`).
- **Model weight tuning** — inspect and adjust the live scoring-model weights
  (`app/api/admin/weights`, `lib/weights-db.js`).
- **Calibration management** — isotonic calibration curve fitting and inspection
  (`app/api/admin/calibration`, `lib/calibration-db.js`).
- **Fantasy data import tools** — manual import UIs for personnel and schedule data feeding the
  fantasy adjustments (`app/admin/fantasy-personnel`, `app/admin/fantasy-schedule`).
- **Model performance tracker (admin)** — internal win/ROI dashboard, separate from the public
  record page (`app/admin/tracker`).
- **Tweet composer/poster** — manual tweet review and posting UI (`app/admin/tweet`).
- **Access code management** (`app/admin/codes`).
- **API quota monitoring** — tracks usage against rate-limited data providers and alerts when
  approaching quota (`app/api/cron/quota-alert`, `lib/quota-log.js`).
- **Error logging** — centralized server-side error log (`lib/error-log.js`, `app/api/debug`).

| `cron/tweet` | 15:15 daily | Post top picks to X |
| `cron/snapshot` | 23:00 daily | Snapshot daily state |
| `cron/nfl-picks` | Tue 09:00 | Generate NFL picks |
| `cron/nfl-resolve` | 13:00 daily | Resolve NFL picks |
| `cron/weekly` | Sun 15:00 | Weekly summary email |
| `cron/tune-weights` | Sun 08:45 | Retune model weights |

## 10. Standalone Analytics Dashboard (Streamlit)

- A separate Python/Streamlit app (`streamlit_app/`) over the same Elo ratings and 2022–2025
  Retrosheet game logs used by the pick model: power rankings, home-field advantage, scoring
  trends, and team-level records. Not customer-facing — internal/analyst tool.

## 11. Data Sources

- **The Odds API** / **SportsGameOdds API** / **SportsData.io** — live odds and NFL data
- **MLB Stats API** — live boxscores, linescores, schedules
- **Baseball Savant** — batted-ball / wOBA data
- **Retrosheet** — 2022–2025 historical MLB game logs (event files + rosters), used for
  backtesting and Elo
- **nflverse** — player stats, snap counts, next-gen stats, players table (daily ingest)
- **Sleeper API** — fantasy league sync, trending adds
